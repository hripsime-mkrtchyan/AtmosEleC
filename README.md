# AtmosEleC Zooniverse Data Extraction Pipeline


Scripts to parse, date-partition, and assemble crowdsourced classification data from the Zooniverse project AtmosEleC into a consolidated database.


## Overview

This repository contains the extraction and data-wrangling code used to process crowdsourced classifications from the Zooniverse project **"AtmosEleC"**.


### What This Pipeline Does

Zooniverse raw exports deliver data in dense CSV files with embedded JSON payloads (e.g., `annotations`, `metadata`, and `subject_data`). This pipeline:

1. **Extracts & Flattens:** Parses raw Zooniverse export dumps and unpacks nested task responses and subject attributes.
2. **Filters & Cleans:** Removes incomplete attempts, test runs, or outdated workflow versions, and scrubs volunteer identifiers to maintain data privacy.
3. **Aggregates Consensus:** Resolves multiple independent classifications per subject to produce the final curated dataset.

## Data Availability

* **Zooniverse Project:** [[Zooniverse ]](https://www.zooniverse.org/projects/hripsi-19/atmoselec-atmospheric-electricity-for-climate)
* **Dataset:** The processed database generated by these scripts is currently restricted to protect ongoing research. It is available from the corresponding author upon reasonable request.
